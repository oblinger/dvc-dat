# DAT — dvc-dat, the data-artifact layer
`dvc_dat` gives a folder of data a `_spec_.yaml` (metadata, provenance, how it was made) and gives Python a dotted-name namespace (`do.load("catalog.experiment")`) configured by `.datconfig.yaml` mounts. Public on GitHub, version 2.21.0. Documentation starts at [Docs](Docs.md). The agent DAT owns the repo; consumers ([SVP](ha://SVP) first) file what they need in [DAT Inbox](DAT%20Track/DAT%20Inbox/DAT%20Inbox.md). Operating rules: the repo's [CLAUDE.md](../CLAUDE.md).
